# AOC 显示器参数获取与对比工具

从 AOC 官网获取产品参数，保存到本地 SQLite 数据库，再按需选择型号进行对比。支持产品 ID 去重、型号搜索、差异高亮，以及通过 URL 保存和恢复对比选择。

## 项目背景

选购显示器时发现，AOC 的产品型号很多，命名相近的型号也不少。逐个打开官网、来回切换页面核对参数，既费时间，也容易遗漏差异。

于是借助 AI 做了这个获取并对比的小工具：把自己关注的产品链接放进去，获取官网参数后，在同一张表里查看不同型号的区别。工具保留原始参数名称、数值、说明和脚注，方便回到官网核对。

**本工具仅限个人选购显示器时辅助查询、整理和对比使用，请勿滥用。**

## 功能

- **官网参数获取**：输入产品链接，每行一个，成功获取后自动保存。
- **获取与对比分离**：获取后的产品进入“待对比产品”列表，点击“加入对比”才显示在表格中。
- **按产品 ID 去重**：已下载的产品在请求官网前跳过；同一批次中的重复 ID 合并处理。
- **SQLite 本地存储**：数据库和表不存在时自动创建，重新打开页面后载入全部已保存产品。
- **待对比列表管理**：等宽自适应卡片、型号／ID 搜索、数量统计、已选高亮，列表较长时内部滚动。
- **参数对齐与筛选**：按参数名称对齐，支持搜索参数名称或数值、隐藏相同项、高亮不同项及显示原始名称。
- **URL 保存选择**：加入、移除或清空对比时只更新地址，不刷新页面；刷新后恢复对应产品及顺序。
- **一键清空对比**：取消全部对比选择，保留已获取产品。
- **型号复制**：点击产品标题复制型号，成功提示在 800 毫秒后消失；支持回车或空格操作。
- **单产品删除**：二次确认后删除对应本地记录，同时移除其对比列。
- **来源核对**：保留官网链接、抓取时间以及当前对比的 JSON／抓取来源查看。

## 环境要求

- Python 3.9 或以上版本，包含标准库 `sqlite3`。
- 现代浏览器。
- 项目目录具有写入权限，用于创建和保存 SQLite 数据库。
- 首次获取新产品需要联网；查看已保存产品不需要连接 AOC 官网。

仅使用 Python 标准库及浏览器原生能力，无需安装第三方依赖，不需要 API Key，也不需要调用 AI 服务。

## 快速开始

### 1. 启动本地服务

下载项目后，在包含 `aoc_server.py`、`aoc_compare.html` 和建表 SQL 的目录中打开终端，运行：

```shell
python aoc_server.py
```

浏览器打开终端打印的地址，默认是：

```text
http://127.0.0.1:8765/
```

终端可能打印带 `?run=...` 运行标识的地址，直接使用该地址即可。按 `Ctrl+C` 停止服务。

如果默认端口被占用，可以指定其他端口：

```shell
python aoc_server.py --port 8766
```

然后打开：

```text
http://127.0.0.1:8766/
```

服务只绑定本机 `127.0.0.1`。请通过本地服务打开页面，不要直接双击 HTML 文件。

### 2. 获取关注的产品

从 AOC 官网复制产品详情页链接，在输入框中每行填写一个。例如以下真实产品页面：

```text
https://www.aocmonitor.com.cn/product-16114.html
https://www.aocmonitor.com.cn/product-16540.html
```

点击“获取产品”，获取成功的产品会进入下方“待对比产品”列表，并保存到本地数据库。已有 ID 自动跳过，获取失败的产品可在排查原因后重试。

当前仅支持以下域名及产品路径：

```text
https://www.aocmonitor.com.cn/product-数字.html
```

工具不设获取条数上限，单批最多并发 4 个请求。请只输入实际关注的产品，不要枚举 ID 或批量遍历全站。

### 3. 选择与对比

1. 使用型号或 ID 搜索待对比产品。
2. 点击卡片中的“加入对比”。
3. 在表格中查看参数，按需启用“隐藏相同项”“高亮不同项”等选项。
4. 点击表头“移除对比”，取消某个产品的选择。
5. 点击“清空全部对比”，一次取消全部选择。

“移除对比”和“清空全部对比”只改变当前选择，不会删除数据库中的产品。

### 4. 保存或恢复对比组合

选择产品后，页面自动将对应产品 ID 写入 URL，例如：

```text
http://127.0.0.1:8765/?compare=16114&compare=16540
```

更新 URL 使用 `history.replaceState()`，不会刷新页面，也不会因为每次选择而新增浏览历史记录。已有的其他查询参数和锚点会保留。

可以收藏或复制当前地址。下次启动本地服务并打开该地址，会从 SQLite 中恢复对应产品及选择顺序。重复 ID 自动去重，不存在于本地数据库中的 ID 会跳过。

**URL 只保存选择，不包含产品参数。** 在另一台电脑上使用该地址时，需要先获取对应产品，且本机服务地址、端口必须与访问地址匹配；`127.0.0.1` 地址不能让其他人直接访问你的电脑。

## 数据保存与更新

数据库位于脚本同目录：

```text
aoc_parameters.sqlite3
```

- 启动时自动创建数据库及 `products` 表，无需手动执行建表命令。
- 表结构由 `001_create_aoc_products.sql` 提供，使用 `CREATE TABLE IF NOT EXISTS`，可重复执行。
- 产品路径中的数字作为唯一 ID，协议、查询参数和数字前导零不会产生不同记录。
- 每款产品成功后独立事务提交，重复 ID 不覆盖已有记录。
- 已下载产品不会自动重新抓取或定时更新。
- 如需更新某款产品，先在待对比列表中点击“删除”，确认后重新获取其官网链接。
- 删除会移除该产品的本地记录；工具没有撤销删除功能，重新获取时以官网当时的数据为准。
- 旧 JSON 文件不自动迁移，也不会被工具主动删除。当前不再从 JSON 文件载入产品库。

HTTP 接口和终端输出仍使用 JSON 作为传输格式，参数列表在 SQLite 字段中序列化保存；这与使用 JSON 文件作为本地数据库不同。

备份或迁移时，先停止服务，再复制 `aoc_parameters.sqlite3`。本地数据库及其临时文件建议单独备份，不纳入源码版本管理。

## 参数对比规则

- 按参数名称对齐，不依赖官网表格的行顺序。
- 只合并代码中明确维护的同义名称；未知名称保留，不做模糊推断。
- 仅规范全半角、大小写、空白以及数字之间的 `x`／`×`，不擅自换算单位。
- “最大分辨率”与“分辨率”、色域覆盖率与色域容积等不同含义的字段不会自动合并。
- 同一参数的多条记录完整展示，不覆盖前面的数值。
- “未列出”表示官网参数表没有提供该项，不代表产品不支持。
- 原表空值与缺失参数分别处理；只选择一款产品时不判定参数差异。
- 保留测试条件、数据说明和脚注，不把不同条件下的数值视为同一个结论。

工具用于整理公开规格，不会自动评测屏幕，也不会据此判断实际色准、亮度均匀度、灰阶表现或产品优劣。选购前请结合官方说明和可靠实测核对。

## 主要文件

- `aoc_server.py`：本地 HTTP 服务、官网参数抓取、解析及 SQLite 数据管理。
- `aoc_compare.html`：产品获取、待对比列表、参数表格和 URL 选择恢复。
- `001_create_aoc_products.sql`：可重复执行的建表脚本。
- `README.md`：项目介绍及当前使用说明。
- `aoc_parameters.sqlite3`：启动后自动创建的本地产品数据库。

## 常见问题

### 页面无法打开

确认 Python 服务仍在运行，浏览器访问的端口与启动时一致。端口被占用时，服务会提示并退出，不会自动结束已有进程或更换端口。

### 修改 HTML 后没有看到变化

刷新已打开的页面。服务每次请求都会读取磁盘上的 HTML。修改 Python 服务代码后，需要停止旧服务并重新启动。

### 再次获取时显示“跳过”

对应产品 ID 已存在于本地数据库，这是去重行为。如需更新数据，先确认删除该产品，再重新获取。

### 获取失败或找不到参数表

先确认链接属于支持的官网产品页，并检查网络连接。当前解析官网参数表及页面内嵌的 Nuxt 参数内容；网站结构变化、验证码或访问限制可能导致获取失败。单个页面读取上限为 5MB，网络连接超时为 25 秒。

遇到限制请停止频繁重试，不要尝试绕过；反馈问题时可附上产品链接、错误信息和 Python 版本。

### 型号复制失败

请使用现代浏览器，通过本地服务地址访问，并检查浏览器是否允许剪贴板写入。复制成功后会显示短暂提示，失败时不会误报成功。

### 刷新后没有恢复部分型号

检查地址中是否仍有 `compare` 参数，以及对应 ID 是否存在于当前数据库。清空全部对比后，URL 中的选择也会清除，刷新后不会再次恢复。

## 使用边界

**仅限选购显示器时辅助查询和对比，请勿滥用。**

- 仅获取自己实际关注的少量型号，优先使用本地已保存数据。
- 不用于全站采集、ID 扫描、高频重复请求或商业化数据采集。
- 不绕过验证码、访问限制或其他网站保护措施，遵守数据来源网站的使用规则。
- 不将本地服务部署到公网，也不擅自增加并发给官网造成负担。
- 产品参数和相关内容归其各自权利人所有；本项目为个人辅助工具，并非 AOC 官方产品。
- 数据为抓取时的公开页面内容，可能随官网更新而变化。购买决策请以官方最新信息和实际产品为准。
